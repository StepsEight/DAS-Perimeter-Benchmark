# Contributing

We welcome dataset questions, corrections and reproducible event-recognition methods through GitHub Issues and pull requests.

For a benchmark result, include the dataset version, representation, fixed split files, model/code, random seed(s), preprocessing, hyperparameters, checkpoint-selection rule and Accuracy/Macro-P/Macro-R/Macro-F1. Select settings on validation data and report test results after development. Keep the four patches from each source recording together. If a study uses different splits or representations, identify it as a separate protocol rather than directly replacing the reference score.

Please preserve the dataset's CC BY-NC 4.0 attribution and use conditions. Code contributions should be compatible with the repository's MIT code license. Proposals for additional data should include provenance, labels, acquisition conditions, grouping information and permission to share; they are reviewed separately from the fixed v1.0.0 benchmark.
